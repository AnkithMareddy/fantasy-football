# Scouting notes
Durable, reusable observations about teams, coaches, and players — the stuff that doesn't show up
in a single box score but is worth remembering for the rest of the season. Read this at the start
of research; add to it (newest first) when a report run notices something durable enough to matter
again later.

What belongs here: a coach's real tendency (goes pass-heavy even with a big lead, is quick to bench
a struggling starter), a team's actual offensive identity once it's shown up more than once, a
player whose role clearly changed and why, a bye-week or scheduling quirk worth remembering, a
pattern in how a division rival builds their roster or drafts.

What does NOT belong here: single-game stat lines, routine injury updates (those live in
state/injury_overrides.json), anything that's just this week's box score. If it wouldn't still be
true or useful in a month, it doesn't go in this file.

Keep each entry to 1-3 sentences. Cite the games/evidence behind it.
